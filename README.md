**Code Universe** no es solo un repositorio de guías; es un **ecosistema de documentación técnica estandarizado**. Ha sido forjado para centralizar el conocimiento de lenguajes de alto rendimiento bajo una arquitectura modular, formal y visualmente inmersiva.

---

## 🌌 Galaxias del Ecosistema

Cada lenguaje es una "Galaxia" independiente con su propia identidad visual y técnica, integradas en una sola infraestructura de navegación.

| Galaxia | Nodo | Estado | Especialización Técnica |
| :--- | :---: | :--- | :--- |
| **C++** | `cpp` | 🟢 **Active** | C++23, Modern Abstractions & Systems. |
| **Rust** | `rs` | 🟠 **Beta** | Memory Safety, Ownership & Concurrency. |
| **C#** | `cs` | 🟠 **Beta** | .NET Ecosystem, Enterprise Scalability. |
| **C** | `c` | 🟠 **Beta** | Low-level Control & Hardware Foundations. |

---

## 🛠️ Arquitectura de Ingeniería

Para lograr una plataforma de este calibre, se han implementado las siguientes soluciones de software:

* **Modular Theme Overrides:** Sistema de CSS inyectado por lenguaje que cambia la identidad visual (colores, sombras, gradientes) sin afectar la estructura base.
* **Dual-Path i18n:** Arquitectura de internacionalización nativa. Soporte completo para **Español (Root)** e **Inglés (Mirror)** con sincronización de rutas.
* **Asset Management:** Gestión optimizada de vectores (SVG) con soporte para `currentColor` y adaptabilidad a temas claro/oscuro.
* **Standardized Layouts:** Componentes Vue personalizados para garantizar que la documentación sea legible, técnica y libre de distracciones.

## 🚀 Despliegue y Desarrollo local

Este proyecto utiliza **pnpm** para una gestión de dependencias eficiente y **VitePress** como motor de renderizado estático.

```bash
# Instalar dependencias
pnpm install

# Iniciar el núcleo en modo desarrollo
pnpm run docs:dev

# Compilar para despliegue (Producción)
pnpm run docs:build
```
